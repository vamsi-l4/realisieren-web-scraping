Project overview

The two sites expose different record types. The pipeline maps books and quotes into a shared CSV structure while leaving fields empty when they do not apply. Pagination follows each site's “Next” link; the scraper uses a shared Requests session, retries temporary HTTP failures, and logs page progress.
